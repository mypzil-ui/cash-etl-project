# Cash ETL Project

Автоматизированная система обработки кассовых данных для торговой сети.

## Описание

Проект автоматизирует обработку ежедневных выгрузок с кассовых аппаратов магазинов сети.
Система генерирует тестовые данные (эмуляция работы кассового ПО), загружает их в базу данных SQLite и готова к анализу.

## Структура проекта
cash-etl-project/
├── cash.db # База данных SQLite
├── data/ # CSV-выгрузки с касс
│ ├── processed/ # Обработанные файлы
│ └── *.csv # Новые файлы для обработки
├── scripts/
│ ├── generate_data.py # Генератор тестовых CSV-файлов
│ ├── init_db.py # Инициализация базы данных
│ ├── load_to_db.py # Загрузка CSV в БД
│ └── check_db.py # Проверка данных в БД
├── sql/
│ └── create_tables.sql # DDL-скрипт создания таблиц
├── img/ # Скриншоты для отчёта
├── requirements.txt # Зависимости Python
└── README.md
